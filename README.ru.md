# PumpTracker

Трекер дев-кошельков и умных денег на pump.fun (Solana) с алертами и веб-дашбордом.

- **Лента алертов**: новые токены, прошедшие фильтры по деву; запуски отслеживаемых девов; сделки отслеживаемых кошельков; «умные деньги заходят» (несколько сильных кошельков покупают один токен); миграции; сливы девов.
- **Рейтинг девов**: скор 0–100, доля миграций, сливы, средний ATH, история последних запусков.
- **Умные деньги**: рейтинг кошельков по PnL на кривых pump.fun за 7 дней и свой список отслеживаемых.
- **Фильтры** настраиваются прямо в интерфейсе. Алерты можно дублировать в Telegram.

## Запуск

```powershell
cd pumptracker
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env   # и впиши HELIUS_API_KEY
.venv\Scripts\python run.py
```

Дашборд: http://127.0.0.1:8000

## Как это работает

1. `logsSubscribe` по программе pump.fun (`6EF8…F6P`) через WebSocket RPC.
2. Из логов декодируются Anchor-события `CreateEvent`, `TradeEvent`, `CompleteEvent`. Берутся только события, выпущенные самой программой pump.fun: в транзакциях ботов бывают одноимённые события других лаунчпадов.
3. В SQLite (`data/pumptracker.db`) копятся токены (создатель, ATH, миграция, действия дева) и позиции кошельков.
4. Для незнакомого дева при запуске нового токена история подтягивается из RPC: последние N транзакций → поиск `CreateEvent` → состояние bonding curve. Есть лимит в час, чтобы не сжечь кредиты Helius.

### Скор дева (0–100)

| Часть | Макс. | Что считается |
|---|---|---|
| Миграции | 40 | доля мигрировавших токенов, максимум при 25%+ |
| Средний ATH | 25 | насколько близко токены в среднем подходят к миграции |
| Без сливов | 25 | 1 − доля токенов, где дев продал 80%+ до миграции (неизвестно = 12.5) |
| Не серийник | 10 | ≤10 запусков — 10, к 50 запускам — 0 |

65+ хороший, 40–64 средний, ниже 40 плохой.

## Ограничения

- История копится с момента запуска. Чем дольше трекер работает, тем точнее скор и рейтинг.
- PnL кошельков считается только по сделкам на bonding curve (до миграции) и только по тем, что трекер видел сам.
- Часть токенов pump.fun котируется не в SOL или имеет нестандартную кривую. Для них MC и прогресс кривой не считаются (показывается «—»), а дев, сделки и сливы учитываются.
- На бесплатном тарифе Helius одновременно разрешено ограниченное число WebSocket-соединений. Не запускай две копии трекера с одним ключом.

## Telegram

1. Создай бота у @BotFather и получи токен.
2. Напиши боту что-нибудь, затем узнай свой chat id (например, через @userinfobot).
3. Впиши `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`, перезапусти и включи Telegram во вкладке «Фильтры».

## Структура

```
app/parser.py     декодирование событий pump.fun и bonding curve
app/rpc.py        HTTP RPC, подтягивание истории дева, метаданные
app/db.py         SQLite
app/analytics.py  скор дева, вью токена
app/core.py       приём потока, состояние, движок алертов, Telegram
app/main.py       FastAPI: REST + SSE
web/              дашборд (HTML/CSS/JS без сборки)
```
